# Anijjung Village Explorer

ต้นแบบหมู่บ้านจำลอง 3D สำหรับสำรวจอาหาร น้ำ และพลังงานของครัวเรือนในประเทศไทย สร้างด้วย Vite, JavaScript, CSS และ Three.js ไม่มี backend หรือบัญชีผู้ใช้

หมู่บ้านและข้อมูลครัวเรือนเป็นข้อมูลสมมติ ผังนี้เป็นแนวคิด ไม่ใช่หมู่บ้านจริงหรือผังรับรองทางวิศวกรรม รายชื่อแหล่งช่วยเหลือและเรียนรู้เป็นข้อมูลภายนอกจากตารางของผู้ใช้ ยังไม่ได้ตรวจสอบกับหน่วยงาน

## เปิดบนคอมพิวเตอร์ของคุณ

ติดตั้ง Node.js 22.12 ขึ้นไป (แนะนำ Node.js 24 LTS) ดาวน์โหลดจาก GitHub ผ่าน Code → Download ZIP แล้วแตกไฟล์ หรือใช้ `git clone https://github.com/bizbew/anijjung-village.git` เปิด terminal ในโฟลเดอร์ที่มี package.json:

```sh
npm ci
npm run dev
```

เปิด URL ที่ terminal แสดง โดยปกติคือ http://localhost:5173 บนเครื่องของคุณเอง URL localhost ของเครื่อง Cloud ไม่สามารถเปิดจากคอมพิวเตอร์ของคุณได้โดยตรง ต้นแบบนี้ยังไม่ได้ deploy เป็นเว็บไซต์สาธารณะ

```sh
npm run build
npm test
npm run preview
```

## ใช้งาน

- ลากเพื่อหมุน เลื่อนล้อเมาส์หรือจีบนิ้วเพื่อซูม คลิกขวาลากหรือใช้สองนิ้วเพื่อเลื่อน
- คลิก/แตะบ้าน หรือเลือกปุ่ม 01–05 เพื่อดูข้อมูล กรอบสีทองแสดงบ้านที่เลือก
- กลับมุมเริ่มต้นเพื่อคืนตำแหน่งกล้อง ปิดรายละเอียดหรือกด Escape เพื่อปิดแผง
- แสดงเครือข่ายแบ่งปันเชื่อมเฉพาะบ้านที่สนใจแบ่งปัน เส้นเป็นภาพประกอบ ไม่ใช่การส่งมอบหรือความพร้อมที่ยืนยันแล้ว
- บนมือถือ แผงรายละเอียดอยู่ด้านล่างและเลื่อนอ่านได้

## ไฟล์ที่แก้ไขได้

- `src/households.js`: ข้อมูลบ้านทั้งห้าและสูตรวันสำรองน้ำ `waterLitres / dailyWaterLitres` ใช้ปริมาณน้ำรวมทั้งครัวเรือนต่อวัน ถ้าเป็นศูนย์หรือไม่มีข้อมูลจะแสดง “ยังคำนวณไม่ได้”
- `src/scene.js`: รูปทรงบ้าน ภูมิทัศน์ กล้อง OrbitControls การเลือกบ้าน และเส้นแบ่งปัน
- `src/main.js`: ปุ่มและแผงรายละเอียดภาษาไทย
- `src/style.css`: สี รูปแบบ และหน้าจอมือถือ

ไม่ยืนยันว่าน้ำเก็บไว้ดื่มได้ ไม่ใช้ตัวเลขผลิตไฟฟ้ารายวันเป็นหลักฐานว่าจะใช้งานระหว่างไฟดับ ไม่สร้างคะแนนความพร้อมหรืออ้างความพึ่งตนเอง 100%

## ตรวจด้วยตนเอง

1. หมุน ซูม และเลื่อนกล้อง ตรวจว่าไม่ลงใต้ดินหรือหลุดไกลจากหมู่บ้าน
2. แตะบ้านทั้งห้า ตรวจชื่อและข้อมูล บ้าน 04 และ 05 ต้องแสดง “ยังคำนวณไม่ได้”
3. ลากผ่านบ้านแล้วปล่อย ต้องไม่เปิดรายละเอียดโดยบังเอิญ
4. เปลี่ยนมุมกล้องแล้วกดกลับมุมเริ่มต้น
5. เปิด/ปิดเครือข่าย ตรวจเส้นเชื่อมบ้าน 02, 03 และ 05 และข้อความอธิบาย
6. ใช้มือถือแนวตั้ง/แนวนอน ตรวจแผงด้านล่าง การเลื่อนอ่าน และการแตะบ้าน

ใช้ WebGL และรูปทรงที่สร้างจากโค้ด ไม่มีโมเดลหรือรูปภาพภายนอก หาก WebGL ใช้งานไม่ได้ ยังอ่านข้อมูลบ้านผ่านปุ่มหมายเลขได้

## แหล่งช่วยเหลือและเรียนรู้

เปิดปุ่ม “แหล่งช่วยเหลือและเรียนรู้” หรือคลิกหลังคาศาลาส่วนกลางในฉาก เพื่อดูรายการภายนอกหมู่บ้านทั้งหมด 30 แห่ง แยกเป็นอาหาร น้ำ และพลังงาน หมวดละ 10 แห่ง ค้นหาจากชื่อ พื้นที่บริการ หรือคำอธิบายได้ ลิงก์เว็บไซต์/ติดต่อและแหล่งอ้างอิงเปิดในแท็บใหม่

ข้อมูลแยกอยู่ใน `src/resources.json` แต่ละรายการมี `id`, `category`, `name`, `area`, `summary`, `url`, `sourceUrl`, `sourceName` และ `verifiedAt` วันที่ตรวจสอบเป็น `null` จนกว่าจะตรวจสอบจริง ไม่เพิ่มเบอร์โทรหรือพิกัดที่ไม่มีในตาราง ไม่ปักสถานที่ภายนอกลงในผังจำลอง และไม่ยืนยันว่ามีทรัพยากรพร้อมแจกหรือเปิดรับบริการ

แผงแหล่งข้อมูลแยกจากแผงบ้าน เปิดครั้งละหนึ่งแผงเพื่อไม่บดบังฉาก บนมือถือแผงแหล่งข้อมูลอยู่ด้านล่าง เลื่อนอ่านได้ ปิดด้วยปุ่มหรือ Escape ส่วนข้อมูลครัวเรือนและเครือข่ายแบ่งปันยังใช้ข้อมูลจำลองเดิม
