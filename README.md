# Anijjung Village Explorer

ต้นแบบหมู่บ้านจำลอง 3D สำหรับสำรวจอาหาร น้ำ และพลังงานของครัวเรือนในประเทศไทย สร้างด้วย Vite, JavaScript, CSS และ Three.js ไม่มี backend หรือบัญชีผู้ใช้

หมู่บ้านและข้อมูลครัวเรือนเป็นข้อมูลสมมติ ผังนี้เป็นแนวคิด ไม่ใช่หมู่บ้านจริงหรือผังรับรองทางวิศวกรรม รายชื่อแหล่งช่วยเหลือและเรียนรู้เป็นข้อมูลภายนอกจากตารางของผู้ใช้ ยังไม่ได้ตรวจสอบกับหน่วยงาน

## เปิดบนคอมพิวเตอร์ของคุณ

ติดตั้ง Node.js 22.12 ขึ้นไป (แนะนำ Node.js 24 LTS) ดาวน์โหลดจาก GitHub ผ่าน Code → Download ZIP แล้วแตกไฟล์ หรือใช้ `git clone https://github.com/bizbew/anijjung-village.git` เปิด terminal ในโฟลเดอร์ที่มี package.json:

```sh
npm ci
npm run dev
```

เปิด URL ที่ terminal แสดง โดยปกติคือ http://localhost:5173 บนเครื่องของคุณเอง URL localhost ของเครื่อง Cloud ไม่สามารถเปิดจากคอมพิวเตอร์ของคุณได้โดยตรง ดูขั้นตอนเผยแพร่เว็บไซต์ในหัวข้อ GitHub Pages ด้านล่าง

```sh
npm run build
npm test
npm run preview
```

## ใช้งาน

- ลากเพื่อหมุน เลื่อนล้อเมาส์หรือจีบนิ้วเพื่อซูม คลิกขวาลากหรือใช้สองนิ้วเพื่อเลื่อน
- คลิก/แตะบ้าน หรือเลือกปุ่ม 01–05 เพื่อดูข้อมูล กรอบสีทองแสดงบ้านที่เลือก
- กลับมุมเริ่มต้นเพื่อคืนตำแหน่งกล้อง ปิดรายละเอียดหรือกด Escape เพื่อปิดแผง
- แสดงเครือข่ายแบ่งปันเชื่อมเฉพาะบ้านที่สนใจแบ่งปัน เส้นเป็นภาพประกอบ ไม่ใช่การส่งมอบหรือความพร้อมที่ยืนยันแล้ว
- บนมือถือ แผงรายละเอียดอยู่ด้านล่างและเลื่อนอ่านได้

## ไฟล์ที่แก้ไขได้

- `src/households.js`: ข้อมูลบ้านทั้งห้าและสูตรวันสำรองน้ำ `waterLitres / dailyWaterLitres` ใช้ปริมาณน้ำรวมทั้งครัวเรือนต่อวัน ถ้าเป็นศูนย์หรือไม่มีข้อมูลจะแสดง “ยังคำนวณไม่ได้”
- `src/scene.js`: รูปทรงบ้าน ภูมิทัศน์ กล้อง OrbitControls การเลือกบ้าน และเส้นแบ่งปัน
- `src/main.js`: ปุ่มและแผงรายละเอียดภาษาไทย
- `src/style.css`: สี รูปแบบ และหน้าจอมือถือ

ไม่ยืนยันว่าน้ำเก็บไว้ดื่มได้ ไม่ใช้ตัวเลขผลิตไฟฟ้ารายวันเป็นหลักฐานว่าจะใช้งานระหว่างไฟดับ ไม่สร้างคะแนนความพร้อมหรืออ้างความพึ่งตนเอง 100%

## ตรวจด้วยตนเอง

1. หมุน ซูม และเลื่อนกล้อง ตรวจว่าไม่ลงใต้ดินหรือหลุดไกลจากหมู่บ้าน
2. แตะบ้านทั้งห้า ตรวจชื่อและข้อมูล บ้าน 04 และ 05 ต้องแสดง “ยังคำนวณไม่ได้”
3. ลากผ่านบ้านแล้วปล่อย ต้องไม่เปิดรายละเอียดโดยบังเอิญ
4. เปลี่ยนมุมกล้องแล้วกดกลับมุมเริ่มต้น
5. เปิด/ปิดเครือข่าย ตรวจเส้นเชื่อมบ้าน 02, 03 และ 05 และข้อความอธิบาย
6. ใช้มือถือแนวตั้ง/แนวนอน ตรวจแผงด้านล่าง การเลื่อนอ่าน และการแตะบ้าน

ใช้ WebGL และรูปทรงที่สร้างจากโค้ด ไม่มีโมเดลหรือรูปภาพภายนอก หาก WebGL ใช้งานไม่ได้ ยังอ่านข้อมูลบ้านผ่านปุ่มหมายเลขได้

## แหล่งช่วยเหลือและเรียนรู้

เปิดปุ่ม “แหล่งช่วยเหลือและเรียนรู้” หรือคลิกหลังคาศาลาส่วนกลางในฉาก เพื่อดูรายการภายนอกหมู่บ้านทั้งหมด 393 แห่ง แบ่งเป็นอาหาร 86 แห่ง น้ำ 297 แห่ง และพลังงาน 10 แห่ง ค้นหาจากชื่อ พื้นที่บริการ หรือคำอธิบาย และกรองจังหวัดได้ ลิงก์เว็บไซต์/ติดต่อและแหล่งอ้างอิงเปิดในแท็บใหม่

ข้อมูลแยกอยู่ใน `src/resources.json` แต่ละรายการมี `id`, `category`, `name`, `area`, `summary`, `url`, `sourceUrl`, `sourceName` และ `verifiedAt` วันที่ตรวจสอบเป็น `null` จนกว่าจะตรวจสอบจริง ไม่เพิ่มเบอร์โทรหรือพิกัดที่ไม่มีในตาราง ไม่ปักสถานที่ภายนอกลงในผังจำลอง และไม่ยืนยันว่ามีทรัพยากรพร้อมแจกหรือเปิดรับบริการ

แผงแหล่งข้อมูลแยกจากแผงบ้าน เปิดครั้งละหนึ่งแผงเพื่อไม่บดบังฉาก บนมือถือแผงแหล่งข้อมูลอยู่ด้านล่าง เลื่อนอ่านได้ ปิดด้วยปุ่มหรือ Escape ส่วนข้อมูลครัวเรือนและเครือข่ายแบ่งปันยังใช้ข้อมูลจำลองเดิม

## ภาพหมู่บ้านและธรรมชาติ

บ้านมีโทนสีต่างกัน พร้อมระเบียงยกพื้น บันได ราวไม้ กรอบหน้าต่างและกระถางต้นไม้ ทางเดินโค้งเชื่อมพื้นที่กลาง แนวต้นไม้และพุ่มไม้ล้อมหมู่บ้าน มีแปลงผักส่วนกลาง พืชริมบ่อ ใบบัวและม้านั่ง ทุกอย่างสร้างด้วย geometry ไม่มีโมเดลหรือภาพภายนอก

แก้บ้าน กล้อง และแสงใน `src/scene.js` แก้ต้นไม้ สวนผักและพืชริมบ่อใน `src/landscape.js` การจัดต้นไม้เป็นแบบคงที่เพื่อให้ตำแหน่งเหมือนเดิมทุกครั้ง เงาของอาคารและภูมิทัศน์คำนวณครั้งเดียวเพื่อลดงานระหว่างหมุนกล้อง

## เมนูเครือข่ายและข้อมูลทดลองในเบราว์เซอร์

- `#who-we-are`: รู้จักแนวคิด Anijjung Network และขอบเขตโครงการ
- `#join`: เพิ่มครัวเรือน ชื่อ จำนวนสมาชิก จังหวัด/อำเภอ ช่องทางติดต่อ และความสนใจแบ่งปัน ข้อมูลน้ำ อาหารและไฟฟ้าเว้นว่างได้ เมื่อบันทึกแล้วเพิ่มบ้านในผังและโหลดฉากใหม่ ผังทดลองรองรับบ้านเพิ่มเติม 4 หลัง บ้าน 06–09 ตำแหน่งเป็นสมมติ
- `#sharing`: เลือกบ้านที่สนใจแบ่งปัน แล้วสร้างรายการพร้อมจำนวน หน่วย ราคา (0 คือฟรี) พื้นที่และเงื่อนไข รายการไม่สร้างจากทรัพยากรสำรองอัตโนมัติ ปุ่มขอแบ่งปันบันทึกชื่อ ช่องทางติดต่อ จำนวนและข้อความ พร้อมยอดประมาณการ ไม่หักจำนวน ไม่ส่งข้อความ ไม่รับชำระเงิน และไม่ถือว่าอนุมัติแล้ว

ข้อมูลเก็บใน localStorage ชื่อ `anijjung-network-v1` ของ origin ที่เปิดแอป เปลี่ยนเครื่อง เบราว์เซอร์ พอร์ต หรือ origin จะไม่เห็นข้อมูลร่วมกัน ล้างข้อมูลเว็บไซต์แล้วข้อมูลจะหาย คนที่ใช้เบราว์เซอร์เดียวกันเข้าถึงข้อมูลที่เก็บได้ จึงควรใช้ข้อมูลทดลอง ช่องทางติดต่อไม่แสดงในรายการหรือรายละเอียดบ้าน ไม่มี backend หรือระบบยืนยันเจ้าของบ้าน

แก้หน้าและฟอร์มใน `src/network-pages.js` แก้ schema และการบันทึกใน `src/network-store.js` ส่วนบ้านตัวอย่างอยู่ใน `src/households.js` และตำแหน่งบ้านใหม่อยู่ใน `slots` ของ network-store.js

ตรวจด้วยตนเอง: เปิดเมนูทั้งสาม เพิ่มบ้านพร้อมเลือกความสนใจ กลับหน้าแรกและรีเฟรช ตรวจบ้านใหม่และข้อมูลที่ไม่ทราบ เพิ่มรายการราคา 0 และราคามากกว่า 0 ทดลองขอจำนวนไม่เกินที่เสนอ ตรวจยอดประมาณการ และรีเฟรชเพื่อดูคำขอที่บันทึกไว้ บนมือถือใช้เมนู ☰

## GitHub Pages

เว็บไซต์เตรียม deploy ที่ https://bizbew.github.io/anijjung-village/ โดย GitHub Actions จะติดตั้ง dependencies ทดสอบ build และ deploy ไฟล์ใน `dist` เมื่อ push ไป `main` หรือสั่ง Run workflow ด้วยตนเอง ไม่ใช้ source บน branch เป็นเว็บไซต์โดยตรง

ตั้งค่าใน repository ครั้งแรก: **Settings → Pages → Build and deployment → Source → GitHub Actions** จากนั้นเปิด **Actions → Deploy to GitHub Pages** เพื่อตรวจผล หาก workflow ก่อนหน้าล้มเหลวเพราะยังไม่ได้เลือก Source ให้กด **Re-run all jobs** หลังตั้งค่าแล้ว ตรวจว่า repository อนุญาต Actions และการ deploy จาก branch `main` ใน environment `github-pages`

`vite.config.js` ตั้ง base path สำหรับ production เป็น `/anijjung-village/` ส่วน `npm run dev` ยังเปิดที่ root ตามเดิม เมนูใช้ hash routes จึงไม่ต้องมี server rewrite สำหรับหน้าย่อย

ตรวจ production บนเครื่อง: `npm run build` แล้ว `npm run preview` จากนั้นเปิด URL ที่ terminal แสดง ตามด้วย `/anijjung-village/` หากเปลี่ยนชื่อ repository หรือใช้ custom domain ต้องปรับ base path ให้ตรง URL ใหม่

ข้อมูล localStorage ของ localhost และ GitHub Pages แยกกัน บ้านและรายการที่เพิ่มในเครื่องจะไม่ตามไปยังเว็บไซต์ และข้อมูลแต่ละผู้ใช้ยังไม่แชร์กัน

## การนำเข้าศูนย์อาหารและน้ำจาก Excel

เพิ่มข้อมูลจาก `AI Project - Anijjung Resilience.xlsx` เฉพาะชีต `Food_Center` (78 แถวข้อมูล) และ `Water_Center` (419 แถวข้อมูล) โดยไม่ใช้โน้ตฟีเจอร์หรือคอลัมน์สรุปด้านข้างเป็นคำสั่งหรือรายการศูนย์

- อาหาร: รวมแถวซ้ำของศูนย์พบพระ ตาก และรวมศูนย์มาบเอื้องกับรายการเดิม เพิ่มสุทธิ 76 แห่ง รวม 86 แห่ง
- น้ำ: รวม 419 แถวตามรหัสหน่วยงานเป็น 290 แห่ง เก็บจังหวัดที่เกี่ยวข้องครบ รวมส่วนกลางกรมทรัพยากรน้ำ กรมทรัพยากรน้ำบาดาล และสำนักทรัพยากรน้ำบาดาลเขต 3 เข้ากับรายการเดิม เพิ่มสุทธิ 287 แห่ง รวม 297 แห่ง
- พลังงาน: คง 10 รายการเดิม รวมทุกหมวด 393 แห่ง โดยทั้งอาหารและน้ำมีจังหวัดที่เกี่ยวข้องตามไฟล์ครบ 77 จังหวัด ไม่ใช่การยืนยันบริการทุกพื้นที่
- รายการชื่อคล้ายกันแต่ระบุเป็นศูนย์ย่อย/เครือข่ายต่างกันไม่รวมโดยเดา เช่น ศูนย์เครือข่ายพิพิธภัณฑ์เกษตรกับรายการพิพิธภัณฑ์เดิม

`provinces` ใช้กรองจังหวัดตามแถวต้นทาง แยกจาก `officeProvince` (จังหวัดที่ตั้งสำนักงาน) และ `coverageNotes` (เงื่อนไขพื้นที่บริการ) ตัวอย่างหน่วยงานตั้งที่ตรังอาจปรากฏเมื่อกรองกระบี่ แต่ไม่ได้หมายความว่าตั้งอยู่กระบี่หรือให้บริการทุกแปลง

เก็บแหล่งที่มาใน `sourceFile`, `sourceSheet`, `sourceRows` และลิงก์ที่มีจริง ข้อมูลน้ำมี `sourceResearchedAt` เป็นวันที่สืบค้นตามไฟล์ (2026-09-24) แต่ `verifiedAt` ยังเป็น null เพราะเว็บไซต์นี้ไม่ได้ตรวจยืนยันกับหน่วยงาน ข้อมูลอาหารที่ไม่มีเว็บไซต์หรือเบอร์โทรจะไม่สร้างข้อมูลเหล่านั้นขึ้นเอง รายการแสดงทีละ 12 แห่งและกดแสดงเพิ่มเติมได้

สำหรับนำเข้าไฟล์เดิมซ้ำหรืออัปเดตข้อมูลเพิ่มเติม ใช้ Python พร้อม `openpyxl` แล้วรัน:

```sh
python scripts/import-resource-centers.py "/path/to/AI Project - Anijjung Resilience.xlsx"
```

การนำเข้าไฟล์เดิมซ้ำผ่านการตรวจแล้วว่าไม่เพิ่มรายการซ้ำ ไฟล์ Excel ต้นฉบับไม่ถูกนำขึ้น repository การ build เว็บใช้ JSON ที่นำเข้าไว้ ไม่ต้องติดตั้ง Python หรือเปิดไฟล์ Excel

## จังหวัด/อำเภอ และคำแนะนำการประมาณค่า
